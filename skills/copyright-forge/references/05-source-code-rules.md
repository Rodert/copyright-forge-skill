# Source-Code Rules

This release supports ordinary deposit only. Start with a deterministic manifest:
sorted, first-party, text source files selected from core entry points, routing,
handlers/controllers, services, models, repositories, middleware, algorithms,
and business UI pages. Exclude dependencies, generated outputs, locks, minified
assets, maps, binaries, and caches.

Do not synthesize code, rename symbols, delete business logic, add comments, or
change the input project. Copy, redact, order, and paginate only in output.

Use the applicable official requirements for the final page count, continuity,
layout, header, and end-page treatment. The collector provides a manifest, not
a final legally formatted PDF.
