# Scope and Principles

Copyright Forge prepares drafts from a real project. It is not a legal service,
submission system, or approval guarantee.

Never invent functionality, source code, screenshots, ownership, development
relationships, publication facts, or confirmed dates. Never modify the input
project. Generated source copies may be redacted and reformatted, with every
change recorded.

Use `software-profile.yaml` as the only source for software name, short name,
and version. Feature claims need supporting evidence. When evidence is absent,
omit the claim or request clarification.
