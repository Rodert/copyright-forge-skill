# Identification Material Rules

## CN-SCR-CODE-001

- **Rule**: Ordinary deposit source program and documentation identification
  material uses the first and last 30 consecutive pages; submit all material
  when fewer than 60 pages.
- **Authority**: 国家版权局
- **Source**: `CN-SCR-REG-2002`, 《计算机软件著作权登记办法》第十条
- **Classification**: `law_or_regulation`
- **Applies to**: ordinary deposit
- **Severity**: blocker
- **Last verified**: 2026-09-01

## CN-SCR-CODE-002

- **Rule**: Except for the regulation's stated circumstances, source program
  and documentation identification material should contain no fewer than 50
  lines per page.
- **Authority**: 国家版权局
- **Source**: `CN-SCR-REG-2002`, 《计算机软件著作权登记办法》第十条
- **Classification**: `law_or_regulation`
- **Applies to**: ordinary deposit
- **Severity**: blocker
- **Last verified**: 2026-09-01

Formatting and service-channel details should be checked against
`CN-SCR-SERVICE-PORTAL` before submission. Do not label a local window practice
as a national legal requirement.
