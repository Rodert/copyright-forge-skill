# Ownership and Rights-Chain Rules

Rights ownership, development method, assignment, commissioned development,
joint development, inheritance, and modifications of another party's software
cannot be established by source code alone. Continue technical material work,
but record the evidence and contract facts that a human must verify.

| Rule ID | Classification | Requirement |
| --- | --- | --- |
| CN-SCR-RIGHT-001 | law_or_regulation | Rights-chain facts must be supported by the applicant's real legal documents and confirmations. |
| CFS-RIGHT-001 | best_practice | Do not block project analysis, evidence extraction, documentation drafting, or source selection merely because an ownership scenario is complex. |
