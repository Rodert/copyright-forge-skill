# User Communication

Use ordinary Chinese for ordinary users. Do not expose `software-profile`, rule
IDs, manifests, parsers, or state names unless asked.

First report a short analysis summary, then ask only unresolved facts together.
Ask reality-based questions: who developed it, who will apply, when it was
actually completed, and whether it has been publicly provided. Give a proposed
name/version where evidence supports a recommendation.

Use concise progress messages, for example: "已识别项目结构", "已为 12 个功能建立代码证据",
and "还有 3 项需要确认". At delivery, list user-facing files, remaining risks,
and the plain-language completion state.
