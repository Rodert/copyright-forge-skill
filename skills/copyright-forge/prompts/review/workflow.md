# Diagnose Existing Materials

Inspect the supplied materials and, when available, the corresponding project.
Create or resume a task directory, establish an evidence map, then run the
quality gate. Group results as blockers, high-risk findings, general warnings,
and information. Explain each issue in plain language, its affected file, and
the safe correction. Do not silently rewrite user-provided materials; create
revised drafts only after the user asks for correction or supplies the needed
facts.
