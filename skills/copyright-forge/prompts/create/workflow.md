# Create Materials

1. Initialize an external task directory, scan the project, build the evidence
   map and feature graph. Read the applicable official and material references.
2. Investigate further before asking questions. Build the software profile with
   source, confidence, and confirmation status for every resolved field.
3. Present one confirmation panel containing only unresolved human facts and
   recommendations. Persist answers in `user-confirmations.json`.
4. Validate and lock the profile. After locking, every deliverable reads the
   same profile verbatim.
5. Read `prompts/create/deliverables.md` and generate the user-appropriate
   evidence-backed documentation, source program material, application filling
   guide, evidence list, and quality report.
6. Run all quality gates. Fix unsupported claims and other self-fixable issues,
   regenerate affected outputs, then review again.
