# Copyright Forge Skill

> 실제 프로젝트 증거를 바탕으로 중국 소프트웨어 저작권 등록 자료 초안을 준비합니다.

[简体中文](../README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Русский](README.ru.md) | [Français](README.fr.md)

Copyright Forge는 중국 소프트웨어 저작권 등록을 위한 AI Agent Skill입니다. 실제
프로젝트에서 근거를 추출하고 소프트웨어 정보를 일관되게 관리하여 설명서, 소스 코드
식별 자료 및 신청 항목 작성 초안을 준비합니다.

## Agent에게 바로 전달하기

```text
https://github.com/Rodert/copyright-forge-skill 에서 Copyright Forge Skill을 설치하고 사용하세요.

skills/copyright-forge/SKILL.md를 읽은 뒤, 내 실제 프로젝트를 바탕으로 중국 소프트웨어 저작권 등록 자료 초안을 준비하세요.

매일 첫 자료 준비 전에는 상위 Git 업데이트를 확인하세요. 로컬 작업 트리가 깨끗하고 업데이트가 있으면 fast-forward로 먼저 업데이트합니다. 최신 상태면 알리지 말고, 확인 또는 업데이트 실패나 로컬 변경으로 인한 업데이트 차단 시에는 이유를 알리고 자료 준비를 시작하지 마세요. 로컬 변경을 덮어쓰면 안 됩니다.

실제 프로젝트 증거와 내가 확인한 사실만 사용하세요. 기능, 소스 코드, 스크린샷, 권리 귀속, 개발 관계, 공개 사실 또는 날짜를 만들어 내지 말고, 원본 프로젝트나 공식 양식을 수정하지 마세요. 등록 승인을 보장하지 말고, 출력은 프로젝트 밖의 별도 디렉터리에 저장하며 확인이 필요한 항목을 표시하세요.
```

## 제공 기능

- Go, Java, Python, Node.js, Vue, React 프로젝트 스캔.
- 기능 후보와 코드, 라우트, 모델, 화면 경로의 증거 매핑.
- `software-profile.yaml`을 통한 명칭, 버전, 확인된 사실의 단일 관리.
- 일반 제출용 결정적 소스 목록, 생성 사본에 한정된 민감정보 마스킹, 일관성 검증.

## 신뢰 경계

이 Skill은 신청을 제출하거나 법적 사실을 판단하거나 공식 양식을 변경하지 않으며,
승인을 보장하지 않습니다. 현재 버전은 일반 제출을 지원합니다. 예외 제출과 복잡한
권리 관계는 수동 검토가 필요합니다.

시작점은 [SKILL.md](../skills/copyright-forge/SKILL.md)입니다. 명령 예제와 자세한 내용은
[중국어 README](../README.md)를 참조하세요.
