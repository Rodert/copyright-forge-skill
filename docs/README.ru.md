# Copyright Forge Skill

> Подготовка черновиков материалов для регистрации авторского права на ПО в Китае на основе доказательств из реального проекта.

[简体中文](../README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Русский](README.ru.md) | [Français](README.fr.md)

Copyright Forge — это AI Agent Skill для регистрации авторского права на
программное обеспечение в Китае. Он извлекает проверяемые доказательства из
реального проекта, унифицирует сведения о ПО и помогает подготовить описание,
материалы идентификации исходного кода и черновик данных для заявления.

## Передайте это Agent

```text
Установите и используйте Copyright Forge Skill из https://github.com/Rodert/copyright-forge-skill.

Прочитайте skills/copyright-forge/SKILL.md, затем подготовьте черновики материалов для регистрации авторского права на ПО в Китае на основе моего реального проекта.

Перед первой подготовкой материалов в каждый календарный день проверяйте обновления Skill в вышестоящем Git-репозитории. Если рабочее дерево чистое и доступно обновление, сначала выполните fast-forward. Если обновлений нет, не сообщайте об этом. При ошибке проверки или обновления, а также когда локальные изменения блокируют обновление, объясните причину и не начинайте подготовку. Никогда не перезаписывайте локальные изменения.

Используйте только доказательства из реального проекта и факты, подтверждённые мной. Не выдумывайте функции, исходный код, скриншоты, правообладание, отношения разработки, факты публикации или даты. Не изменяйте проект и официальные формы, не обещайте одобрение регистрации. Сохраняйте результаты в отдельный каталог вне проекта и помечайте поля, требующие моего подтверждения.
```

## Возможности

- Сканирование проектов Go, Java, Python, Node.js, Vue и React.
- Связывание возможных функций с кодом, маршрутами, моделями или страницами.
- Единый `software-profile.yaml` для названия, версии и подтверждённых фактов.
- Детерминированный список исходных файлов для обычной передачи, маскирование только в созданных копиях и проверка согласованности.

## Границы ответственности

Skill не подаёт заявления, не устанавливает юридические факты, не изменяет
официальные формы и не гарантирует одобрение. Текущая версия предназначена для
обычной передачи; исключения и сложные права требуют ручной проверки.

Точка входа: [SKILL.md](../skills/copyright-forge/SKILL.md). Примеры команд и
подробности доступны в [китайском README](../README.md).
