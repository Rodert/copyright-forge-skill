# Copyright Forge Skill

> 実在するプロジェクトの証拠に基づき、中国のソフトウェア著作権登録用資料の草案を作成します。

[简体中文](../README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Русский](README.ru.md) | [Français](README.fr.md)

Copyright Forge は、中国のソフトウェア著作権登録向け AI Agent Skill です。実際の
プロジェクトから根拠を取得し、ソフトウェア情報を統一したうえで、説明書、ソース
プログラム識別資料、申請項目の記入案を準備します。

## Agent にそのまま渡す内容

```text
https://github.com/Rodert/copyright-forge-skill から Copyright Forge Skill をインストールして使用してください。

skills/copyright-forge/SKILL.md を読み、私の実際のプロジェクトに基づいて中国のソフトウェア著作権登録資料の草案を作成してください。

毎日最初の資料作成前に上流 Git 更新を確認してください。ローカルの作業ツリーがクリーンで更新がある場合は fast-forward で更新してから続行します。最新なら通知せず、確認・更新失敗またはローカル変更による更新不可の場合は理由を伝え、資料作成を開始しないでください。ローカル変更を上書きしてはいけません。

実際のプロジェクトと私が確認した事実のみを使用してください。機能、ソースコード、画面、権利帰属、開発関係、公開事実、日付を捏造せず、元プロジェクトや公式申請書を変更せず、登録承認を保証しないでください。出力はプロジェクト外の別ディレクトリに保存し、確認が必要な項目を明示してください。
```

## 主な機能

- Go、Java、Python、Node.js、Vue、React のプロジェクト解析。
- 機能候補とコード、ルート、モデル、画面の証拠対応付け。
- `software-profile.yaml` による名称、バージョン、確認済み事実の一元管理。
- 通常交付向けの決定的なソース選択リスト、生成コピーのみの秘匿情報マスキング、整合性検証。

## 利用上の境界

本 Skill は申請を提出せず、法的事実を判断せず、公式書式を改変せず、承認を保証しません。
現行版は通常交付を対象とし、例外交付や複雑な権利関係は手動確認が必要です。
