# FlowTask Official Demo

这是 Copyright Forge 的公开官方 Demo。它以一个真实可运行的 Vue 3 + TypeScript + Vite 与 FastAPI + SQLite 项目为输入，完整演示一句用户请求如何变成可追溯的软著材料。

> 帮我给这个项目做一个软著。

```text
真实代码项目
  -> Project Scan
  -> Evidence Map / Feature Graph
  -> User Fact Confirmation
  -> Fact Lock
  -> Material Generation
  -> Independent Review
  -> READY
```

## 内容

- `project/`：可运行的 FlowTask 软件项目。
- `input/`：模拟用户请求。
- `analysis/`：由 Copyright Forge 脚本生成的扫描、证据、功能图、事实档案和状态记录。
- `output/`：由已锁定事实和真实代码证据生成的填写指引、软件说明书、源程序材料与质量报告。
- `site/`：无需服务器的静态浏览器 Demo。

所有申请主体和日期均明确标注为公开测试数据；仓库不包含真实身份信息、密钥、Token 或密码。

打开 [静态 Demo](site/index.html) 可查看证据、事实锁定、说明书、源程序分页预览和 Reviewer 结果。
